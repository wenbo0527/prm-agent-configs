> **使用**：选一个最接近你团队的，按需调整

## 📋 选型指南

### 我应该选哪个？

```
问 1：你团队有多少人？
├── 5+ 人 → 团队 1（5 人阵型）
├── 2-4 人 → 团队 2（3 人精简）
└── 1 人   → 团队 3（1 人 PM only）

问 2：项目复杂度？
├── 高（多模块多角色）→ 团队 1
├── 中（单一产品）→ 团队 2
└── 低（个人项目）→ 团队 3

问 3：是否有 PM？
├── 有 → 团队 1 或 团队 2
└── 没有（开发者兼 PM）→ 团队 3
```

| **产品 lead** | 独立 | PM 兼 | — |
| **dev lead** | 独立 | PM 兼 | — |
| **QA** | 独立 | 独立 | 开发者兼 |
| **doc** | 独立 | dev 兼 | — |

| **适合** | 完整产品 | MVP / 早期产品 | 个人项目 |

## 🛡️ 协作硬规则（无论哪个阵型）

- **派给角色，不派给人**
- **update 必 get 实证**
- **反思≠实证** = 0
- **边界守**违例 = 0
- **5min ack** 100%
