# docs/快速开始.md · 5 步搭起你的需求管理 agent 团队

> **作用**：5 分钟搭起一个可工作的产品需求管理 agent 团队

---

## 🚀 5 步快速开始

### 第 1 步：Fork 或 Clone 本仓

```bash
git clone https://github.com/wenbo0527/prm-agent-configs.git
cd prm-agent-configs
```

### 第 2 步：选你的团队阵型

参考 `roles/README.md`，根据团队规模选一个：

| 规模 | 阵型 | 文件 |
|:--|:--|:--|
| **5 人** | PM + 产品 + dev + QA + doc | [团队1-5人阵型.md](../roles/团队1-5人阵型.md) |
| **3 人** | PM + dev + QA | [团队2-3人精简.md](../roles/团队2-3人精简.md) |
| **1 人** | PM only | [团队3-1人PM-only.md](../roles/团队3-1人PM-only.md) |

### 第 3 步：装模板骨架

以 5 人阵型为例：

```bash
# 创建 agent workspace 目录
mkdir -p ~/my-agent-team/{pm,product,dev,qa,doc}
cd ~/my-agent-team

# 复制通用模板（每个角色都需要）
for agent in pm product dev qa doc; do
  cp /path/to/prm-agent-configs/templates/AGENTS.md.template $agent/AGENTS.md
  cp /path/to/prm-agent-configs/templates/SOUL.md.template $agent/SOUL.md
  cp /path/to/prm-agent-configs/templates/USER.md.template $agent/USER.md
  cp /path/to/prm-agent-configs/templates/IDENTITY.md.template $agent/IDENTITY.md
  cp /path/to/prm-agent-configs/templates/TOOLS.md.template $agent/TOOLS.md
  cp /path/to/prm-agent-configs/templates/HEARTBEAT.md.template $agent/HEARTBEAT.md
done

# PM 角色专属模板
cp /path/to/prm-agent-configs/templates/PM专属/PM-AGENTS.md.template pm/PM-AGENTS.md
cp /path/to/prm-agent-configs/templates/PM专属/PM-任务派工SOP.template pm/PM-任务派工SOP.md
cp /path/to/prm-agent-configs/templates/PM专属/PM-边界守.template pm/PM-边界守.md
```

### 第 4 步：填模板

**优先级必填**（按 SOUL.md.template 中标注）：

1. **SOUL.md** — 角色身份定义（每个 agent）
2. **USER.md** — 用户上下文（每个 agent 都要知道自己服务谁）
3. **PM-AGENTS.md**（仅 PM） — PM 专属工作流
4. **PM-任务派工SOP.md**（仅 PM） — PM 派工硬规则

**选填**：

- IDENTITY.md — 角色名片（可选但推荐）
- TOOLS.md — 本地工具笔记（按需）
- HEARTBEAT.md — 定时检查（cron 触发的 agent 必填）

### 第 5 步：读教训 + 启动

每个 agent 启动时必读 `lessons/` 下的范式（详见 [lessons/README.md](../lessons/README.md)）。

启动流程：
1. 读 SOUL.md / USER.md
2. 读 AGENTS.md
3. 读对应 lessons（如 PM 必读"派单SOP-不越级"）
4. 读 HEARTBEAT.md（如有）
5. 启动！

## 🎯 第一个任务实战

```bash
# PM 接到一个需求："我要做一个登录功能"

# 1. 需求采集（PM）
打开 brainstorming skill → 输出"一句话需求 + 范围边界"

# 2. PRD 撰写（PM）
打开 prd-generation skill → 输出 PRD.md

# 3. 需求拆解（PM）
打开 requirement-breakdown skill → 输出 WBS + 子任务

# 4. 派工（PM）
打开 agent-task-board skill → 输出 TASK-ID + 5 件套

# 5. 跟踪（PM）
打开 task-canvas-analysis skill → 每日看 in_progress 任务

# 6. 验收（PM）
打开 code-review skill（如有代码）→ cross-check ≥ 2 维度

# 7. 闭环（PM）
写闭环报告 + 更新 MEMORY + 教训沉淀
```

## ❓ 常见问题

### Q1：一定要 fork 才能用吗？

不是。可以直接 clone，或者把模板文件 copy 到你的项目里。

### Q2：5 人阵型必须有 5 个 agent 吗？

不是。`roles/` 下有 1 人 / 3 人 / 5 人版本，按需选。

### Q3：可以改模板吗？

可以。模板是 `.template` 后缀，本身就是给你改的。但改完请不要往本仓提 PR（除非贡献）。

### Q4：怎么贡献？

参考 [CONTRIBUTING.md](../CONTRIBUTING.md)。

### Q5：脱敏 SOP 在哪？

[docs/脱敏SOP.md](脱敏SOP.md)。推前必读。
