# design SOP · 视觉设计（v1.1）

> **阶段**：04 交互设计
> **目标**：把交互方案转成视觉设计

---

## 🎯 触发条件

- ✅ 交互方案已锁定
- ✅ 需要做视觉风格
- ✅ 设计规范需要建立

## 🛠️ 操作步骤（5 步）

### 第 1 步：定义设计语言

| 维度 | 选择 |
|:--|:--|
| **风格** | 现代 / 简约 / 商务 / 活泼 |
| **主色** | [品牌色] |
| **辅色** | [次要色] |
| **字体** | [中文] + [英文] |
| **图标** | [风格] + [库] |
| **间距** | 4 / 8 / 12 / 16 / 24 |

### 第 2 步：组件库选型

| 库 | 适用 |
|:--|:--|
| **Ant Design** | 后台 / B 端 |
| **Arco Design** | 字节系 / 中后台 |
| **Material UI** | Material 风格 |
| **shadcn/ui** | 现代 + 可定制 |
| **自研** | 独特品牌 |

**反范式**：自研组件库（成本高）→ 用成熟库

### 第 3 步：关键页面设计

| 页面 | 优先级 |
|:--|:--|
| 首页 / 落地页 | P0 |
| 核心流程页 | P0 |
| 表单 / 详情 | P1 |
| 设置 / 关于 | P2 |

### 第 4 步：响应式 + 可访问性

```
断点：
- 移动端：< 768px
- 平板：768-1024px
- 桌面：> 1024px

可访问性（A11Y）：
- 颜色对比度 ≥ 4.5:1
- 键盘可导航
- 屏幕阅读器友好
```

### 第 5 步：设计 Review

```
Review 清单：
- [ ] 视觉风格统一？
- [ ] 组件用法一致？
- [ ] 间距 / 颜色符合规范？
- [ ] 响应式覆盖 3 个断点？
- [ ] A11Y 基础达标？
- [ ] 交付物归档？
```

## ✅ 验收 Checklist

- [ ] 设计语言 6 维度齐全？
- [ ] 组件库选型有理由？
- [ ] 关键页面 P0 全设计？
- [ ] 响应式 3 断点？
- [ ] A11Y 基础达标？

## 🩸 反范式

- **风格不统一** → 视觉割裂
- **自研组件** → 浪费
- **忽略响应式** → 移动端崩
- **没 A11Y** → 失用户
