# reqdef-skill SOP · AI 需求定义（v1.1）

> **阶段**：02 需求定义
> **目标**：用 AI 辅助生成 / 优化 PRD 草稿

---

## 🎯 触发条件

- ✅ PRD 初稿需要快速产出
- ✅ 想用 AI 优化需求结构
- ✅ 多份类似 PRD 需要模板化

## 🛠️ 操作步骤（4 步）

### 第 1 步：准备输入

把需求理解文档（含用户故事 / NFR / 风险）喂给 AI：

```
Prompt 模板：

你是资深产品经理，请帮我把以下需求理解转成 PRD 草稿。

## 需求理解
[粘贴]

## 输出要求
- 8 个章节齐全
- 每个用户故事有 2-5 个验收标准
- NFR 覆盖 5 类（性能 / 安全 / 可扩展 / 可维护 / 兼容）
- 风险评估表
- 优先级排序（MVP / P1 / P2 / P3）

## 输出格式
Markdown
```

### 第 2 步：AI 生成 + 人工 review

```
✅ AI 输出 PRD v0.1
✅ 产品经理 review（业务准确性）
✅ 修改（AI 容易夸大"价值"，要砍）
✅ AI 输出 PRD v0.2
✅ 锁定 v1.0
```

### 第 3 步：AI 验证 checklist

用 AI 检查 PRD 完整性：

```
Prompt：

请检查以下 PRD 是否完整：
- [8 章节齐全]
- [用户故事 ≥ 5]
- [每个故事 2-5 验收]
- [NFR 5 类]
- [风险评估]
- [里程碑]

PRD：
[粘贴]

输出：缺失项清单
```

### 第 4 步：归档

- 存到 `docs/PRD/<需求名>-v1.0.md`
- 链接到 task board
- 通知 review 角色

## ✅ 验收 Checklist

- [ ] Prompt 模板齐全？
- [ ] AI 输出有 ≥ 1 轮人工 review？
- [ ] AI 完整性检查通过？
- [ ] PRD 归档 + 链接到 task board？

## 🩸 反范式

- **直接用 AI 输出 PRD**：不 review → 业务不准
- **AI = 替代 PM**：AI 是辅助，PM 拍板
- **Prompt 太模糊**：AI 输出不合用 → 多轮迭代
