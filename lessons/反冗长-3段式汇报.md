# 反冗长 · 3 段式汇报范式（v1.0）

> **核心问题**：汇报无重点 / 领导不知道背景 / 决策点模糊
> **锁版守**：任何汇报 = 我在做什么 + 关键进展 + 决策点

---

## 🎯 范式定义

3 段式汇报 = 用固定结构汇报，避免冗长和重点模糊。

## 📋 3 段式结构

### 第 1 段：我在做什么

**1-2 句话讲清角色定位 + 业务主线**

```
✅ "我在做 XX 项目的 YY 模块，负责 ZZ 派工与验收。"
✅ "我在做问小数的生产部署，负责 daemon_loop 进程托管与 smoke test。"
```

**反例**：
```
❌ "最近挺忙的"（无角色定位）
❌ "我做了 X、Y、Z..."（堆任务，缺主线）
```

### 第 2 段：关键进展

**业务语言讲进展，不堆 TASK-ID / 候选号**

```
✅ "诊断器 MVP 完成，5 个端点全 200。"
✅ "派蒙已 broker 派工 3 个 dev 任务，2 个 done 1 个 in_progress。"
```

**反例**：
```
❌ "TASK-001 done，TASK-002 done，TASK-003 in_progress..."（堆 TASK-ID）
❌ "候选 #123 触发候选 #456..."（堆内部代号）
```

### 第 3 段：决策点

**A/B/C 选项 + 我的推荐**

```
✅ "现在阻塞在 X，需上级拍板：
   A. 继续原方案（风险 Y）
   B. 切换方案（成本 Z）
   C. 暂缓（影响 W）
   推荐 B（理由：成本/风险比最优）"
```

**反例**：
```
❌ "您觉得怎么办？"（开放式问题）
❌ "我想做 X"（缺备选）
❌ "可能需要做 X"（模糊）
```

## 🩸 4 类常见冗长

### 冗长 1：堆任务 ID
- **现象**：报告列了一堆 TASK-ID
- **后果**：领导抓不到重点
- **修复**：业务语言 + 分类（完成 / 进行 / 阻塞）

### 冗长 2：缺决策点
- **现象**：报告完就完，没说要决策
- **后果**：领导不知道下一步
- **修复**：必带 A/B/C + 推荐

### 冗长 3：开放式问题
- **现象**："您觉得怎么办？"
- **后果**：领导做决定成本高
- **修复**：给选项 + 推荐

### 冗长 4：冗余背景
- **现象**：讲了半天历史
- **后果**：重点被埋没
- **修复**：3 段式 = 主线 + 进展 + 决策

## 📋 3 段式模板

```markdown
## 汇报

### 1️⃣ 我在做什么
[1-2 句角色定位 + 业务主线]

### 2️⃣ 关键进展
- [业务进展 1]
- [业务进展 2]
- [业务进展 3]

### 3️⃣ 决策点（如有）
- **场景**：[需要决策的问题]
- **A**：[选项 1]
- **B**：[选项 2]
- **C**：[选项 3]
- **推荐**：[我的选择 + 理由]
```

## 📊 反冗长自检

- [ ] 汇报有 3 段？
- [ ] 第 1 段 1-2 句讲清角色？
- [ ] 第 2 段业务语言不堆 ID？
- [ ] 第 3 段有 A/B/C + 推荐？
- [ ] 总字数 < 200 字？

---

*锁版守：3 段式不可少 + 决策点必带选项 + 不堆 TASK-ID*
