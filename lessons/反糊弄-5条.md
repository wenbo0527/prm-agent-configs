# 反糊弄 5 条 · 范式（v1.0）

> **核心问题**：agent 用模糊报告糊弄上级（沉默 / 虚假报告 / 路径虚指 / 缺少验证 / 边界模糊）
> **锁版守**：5 条硬规则，违例 = 反思≠实证

---

## 🎯 范式定义

**糊弄 = 用模糊语言 / 沉默 / 虚假报告让上级以为任务推进了**

5 条反糊弄 = 5 个硬规则，每个针对一种糊弄方式。

## 🛡️ 5 条硬规则

### 规则 1：5min 回报

**问题**：收到派单后沉默 1 小时，让上游以为你没收到
**规则**：收到派单 → 5min 内必 ack（不沉默不阻塞）
**正例**：
```
✅ "收到，已派给 dev lead，预计 X 完成"
✅ "收到，遇到阻塞，需要 Y 决策"
```
**反例**：
```
❌ 沉默 1 小时（让上游以为你没收到）
❌ "我看看"（模糊，无具体动作）
```

### 规则 2：grep 行号实证

**问题**：声明"已完成"但没具体证据
**规则**：任何"已完成"必带 grep / cat / stat 实证
**正例**：
```
✅ "X 已完成。位置：src/X.ts:42。验证：单元测试 3/3 通过。"
```
**反例**：
```
❌ "X 已完成"（无证据）
❌ "X 应该完成了"（模糊）
```

### 规则 3：test -d 路径验证

**问题**：路径描述虚指（说"在 X 路径"但实际不存在）
**规则**：任何路径描述必 `test -d` + `ls -la` 实证
**正例**：
```
✅ "路径 /path/to/X 存在，ls -la 显示 3 个文件"
```
**反例**：
```
❌ "我把它落档到 /path/to/X"（路径可能不存在）
❌ "路径应该是 X"（"应该"= 模糊）
```

### 规则 4：24h 验证

**问题**：重要任务完成后没有 24h 复检
**规则**：重要任务 24h 后必戳破复检
**正例**：
```
✅ "TASK-X 完成后 24h，仍正常。"
✅ "TASK-X 完成后 24h，发现 Y 问题，已修复。"
```
**反例**：
```
❌ close 后不复检（潜在 bug 没发现）
❌ "应该没问题"（模糊）
```

### 规则 5：派蒙边界

**问题**：监控 agent 替你改（监控越权）
**规则**：监控 agent 只监控，不替你改
**正例**：
```
✅ "派蒙发现 Y 异常，已通知 owner，由 owner 修复"
```
**反例**：
```
❌ 派蒙发现异常后自己改（越权）
❌ "派蒙应该已经改了"（反思≠实证）
```

## 🩸 5 类常见糊弄

| 糊弄方式 | 例子 | 触发规则 | 修复 |
|:--|:--|:--|:--|
| **沉默糊弄** | 收到派单不回 | 规则 1 | 5min ack |
| **虚假报告** | "已完成" 无证据 | 规则 2 | grep 行号 |
| **路径虚指** | 说"在 X 路径" 不存在 | 规则 3 | test -d |
| **不复检** | close 后不复检 | 规则 4 | 24h 验证 |
| **监控越权** | 派蒙替你改 | 规则 5 | 派蒙 own scope |

## 📋 反糊弄 Checklist（每次报告前）

- [ ] 报告带具体路径/行号？（规则 2）
- [ ] 报告带 grep/stat 实证命令输出？（规则 2+3）
- [ ] 报告带验收 Checklist？（规则 4）
- [ ] 报告带 cross-check 结果？（规则 4）
- [ ] 5min 内 ack？（规则 1）
- [ ] 没说"差不多 / 应该 / 我觉得"？（规则 2）

## 📊 反糊弄自检（每周）

- [ ] 本周 5min 内 ack 率 100%？
- [ ] 本周报告都有 grep 行号？
- [ ] 本周路径描述都 test -d 验证？
- [ ] 本周 24h 复检都执行？
- [ ] 本周派蒙未越权？
